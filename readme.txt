Simple Matplotlib wrapper to speed up graph generation. Can also generate data at runtime, if given a Cartesian Function.

Future updates will add a Parametric Function processor for more runtime generation of data.

key update feature summary: check github for more information

github: https://github.com/yusufa739/DesmosKiller

For Github: Only the DesmosKiller folder is installed, so all tester files will not be available. You could add them after but you will have to change import path
